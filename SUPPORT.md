# Support

Open an issue at https://github.com/KarmenLoop/skill-api-diagnostics/issues with the version, OS, Python version, exact command, sanitized input, expected result, and actual result. For host issues, include its name/version and whether it discovered SKILL.md.

Use synthetic reproductions. Remove secrets and private records. Security reports follow SECURITY.md. Support is best effort; no response-time guarantee is offered.
